Micosoft_office_google_antigravity_plugin

An Autonomous AI Copilot for Microsoft Office connected with Antigravity

The Problematic: Standard office AI add-ins function merely as isolated sidebar chat windows—they generate markdown text, leaving the user to copy, paste, re-format tables, fix broken numbering, and assemble documents manually. They cannot perceive active document outlines, rewrite paragraphs in place without phantom duplications, or construct publication-grade tables natively.

The Inspiration: This project was directly inspired by Claude's deep desktop and workspace integration into office tools, where models don't just chat—they execute autonomous tools, parse document geometries, and apply changes directly onto the active workspace.

🎨 Open-Source Hobby Scope This software is developed strictly as a personal open-source hobby and engineering exploration. It is NOT built for commercial uses or enterprise resale, but as an open research playground for the developer community.

Turnkey Windows Installation

Run the installer once and launch Microsoft Word. No terminal, Python, or Node.js required.

01

Download Setup

Get GeminiAntigravityOffice_Setup.exe from official GitHub Releases.

02

Run Setup Wizard

Follow the wizard. It automatically configures the daemon, generates root TLS certificates, and sideloads the Office manifest.

03

Open Microsoft Word

Open Word and click the Gemini button in the Home ribbon tab to start your copilot.
