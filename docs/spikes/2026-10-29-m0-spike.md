# M0 Spike results (29 Oct 2026)

## 1. agy stream-json (warm process)

Command:

```
agy --input-format stream-json --output-format stream-json --model <id> [--effort <e>] [--conversation <id>] -p ""
```

- `-p` needs an argument; pass an empty string.
- One NDJSON line per user turn on stdin:
  `{"event": "user", "message": {"content": "<text>"}}`
  - `message` as a plain string → decode error.
  - `message.text` → "message has no content".
- Output: `init` (with `conversation_id`), `step_update` (`step_type: agent_response` + `text_delta`), `result` (`status: SUCCESS|ERROR`, `response`, `error`).
- **The process stays alive between turns and keeps context**: turn 2 answered `PISTACHIO`.
  - Turn 1: first token 9.0 s.
  - Turn 2: first token 5.5 s.
- **Resume works**: a new process with `--conversation <id>` remembered the code word (11.1 s, cold).
- agy adds ~28k input tokens of its own system prompt to every turn, so the realistic warm target is ~5 s, not 3 s.

## 2. Models

- `gemini-3.8-flash-*` works.
- `claude-sonnet-5-5-medium` works (8.5 s cold).
- `gemini-4-argon-medium` fails with `RESOURCE_EXHAUSTED (code 429): Individual quota reached ... Resets in 96h`.
  - This is a **subscription quota**, not a code bug.
  - The error appears in the `result.error` field and as an `AGY_ERROR: {json}` line on stderr (exit code 3).
  - The old daemon dropped stderr and reported success, so the model just looked "broken".
- **Fix:**
  - surface `result.error` / `AGY_ERROR` in the UI;
  - mark models with an exhausted quota in the picker, with the reset time.

## 3. Account

- Login is stored in Windows Credential Manager as `gemini:antigravity`, shared by the Antigravity IDE and CLI.
- A child process started as the same Windows user is already signed in, so automatic auth needs no human step.
- Interactive agy has `/logout` and `/login` (browser flow, `LoginWithBrowser`). There is no non-interactive login subcommand.
- **Switch account plan:** Settings opens a visible agy console, the user does `/logout` and `/login` there, and the daemon polls `agy models` until it works again.
- `/logout` was **not** run during the spike, so the user stays signed in.

## 4. Document snapshot speed (hidden Word instance)

| Document | COM object walk | `WordOpenXML` (one call) + parse |
|---|---|---|
| 23 Registro dei rischi | 7.56 s (624 paras, 513 cells) | **0.19 s** (418 KB, 79 merges) |
| 2 Project charter | 2.17 s | **0.08 s** (108 merges) |

**Decision:** the snapshot is built from **OOXML**. The taskpane calls `body.getOoxml()` (Office.js, WordApi 1.1) and the daemon parses it. This needs no COM document matching and also works where COM is unavailable. COM is used only for native visuals and layout actions.

The PM templates use only the `Normal` style plus direct formatting, so the snapshot must report **formatting** (bold, size, shading, alignment), not only style names.
